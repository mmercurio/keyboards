# Model 100

This is my custom Kaleidoscope firmware for the [Keyboardio Model 100](https://shop.keyboard.io/products/model-100), a unique split, columnar, ergonomic mechanical keyboard.

## Customizations

I've added the Qukeys Dynamic Adjustments customizations from my Atreus firmware. See the Atreus [README](../Atreus/README.md) for details.
